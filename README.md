# Music Player Web App

Music Player Web App is a modern and responsive audio player built with HTML5, CSS3, and JavaScript. The application provides a smooth music listening experience with an attractive user interface and essential playback controls.

## Features
- Play, pause, and skip music tracks
- Responsive and interactive UI
- Audio progress bar and controls
- Smooth music playback experience
- Lightweight and fast performance

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Live Demo
https://music-player1-ebon.vercel.app/

## How It Works
The application uses HTML5 audio features combined with JavaScript functionality to manage music playback and user interactions dynamically.
